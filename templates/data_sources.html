Data Source Control

1. Upload
The source is registered and stored as a controlled version.
2. Validate
The system checks the structure, records and basic data quality.
3. Human Review
An authorised user reviews the source and validation results.
4. Approve
Only approved versions become eligible for VTA analysis.
5. Version Control
New versions do not overwrite historical versions.
6. Audit Trail
Upload, validation, review and approval actions are retained.
