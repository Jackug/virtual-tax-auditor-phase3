Data Sources / Taxpayer Evidence Base

Register, profile, validate, clean, review and approve the data sources that may be used by the Virtual Tax Auditor.

Step 2C Control Principle: Uploading a data source does not make it available to the VTA engine. The original source is retained unchanged. The system profiles the source, identifies quality issues, proposes safe transformations, records exceptions and requires controlled human review before a cleaned version can become available for Taxpayer 360, Risk Assessment or AI Audit Analysis.

Step 2C — Data Quality & Cleaning Controls

2C-1
Profile
Inspect records, columns, data types, missing values, duplicates and structural quality.
2C-2
Classify Issues
Separate safe transformations from issues requiring human review.
2C-3
Propose Cleaning
Generate controlled proposed corrections without modifying the original source.
2C-4
Resolve Exceptions
Human reviewers accept, reject, override or validate exceptions.
2C-5
Clean Version
Generate a controlled cleaned version linked to the original source.
2C-6
Approval & Lineage
Only an approved, traceable version becomes eligible for VTA use.
Data Governance Principle
The original uploaded dataset remains immutable. Every proposed transformation, exception resolution, cleaned version, approval decision and downstream use must remain traceable to the source version from which it originated.
