Step 2C — Data Quality & Transformation

1. Original Data
The original uploaded file is retained and is never overwritten by transformations.
2. Transform
Apply controlled transformations through the Transform Data workspace.
3. Applied Steps
Every transformation is recorded individually and can be edited or deleted.
4. Clean Version
Saving creates a separate clean data file.
5. Human Approval
The clean version must be approved before downstream use.
6. Reject
A reviewer can reject the clean version and return the source to the transformation/review cycle.
