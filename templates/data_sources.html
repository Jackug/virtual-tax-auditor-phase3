DATA & EVIDENCE · STEP 2C

Data Sources / Taxpayer Evidence Base

Register, profile, clean, review and approve the data sources that may be used by the Virtual Tax Auditor.

Step 2C Control Principle: Uploading a data source does not make it available to the VTA. The original source is retained unchanged. Data quality is assessed first. Cleaning is controlled. Exceptions require resolution. A clean version must be approved before the source can be approved for VTA use.
