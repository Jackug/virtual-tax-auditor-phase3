Knowledge governance
Documents are registered and version-controlled before becoming authoritative knowledge for the Virtual Tax Auditor. A document remains Draft until it receives human approval. Only approved knowledge is intended to be available to the VTA retrieval process.
Controlled lifecycle: Register → Draft → Human Review → Approve / Reject → Approved Knowledge → VTA Retrieval

Editing a document creates a new version. Previous versions are retained for auditability and are not silently overwritten.

Knowledge Governance

Each Knowledge Base version is retained for auditability. Editing or replacing a document creates a new version rather than silently overwriting the previous version. The current version must be reviewed by an authorised human before it becomes Approved.

Only Approved knowledge should be used as authoritative knowledge by the Virtual Tax Auditor.
