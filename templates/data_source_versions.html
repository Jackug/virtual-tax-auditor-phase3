Data Governance Rule

Approval is the control point.

Uploading and validating a source does not make it authoritative. Only a human-approved version may be used as an approved VTA data source.

Rejected, Draft, Needs Revision and Superseded versions remain retained for auditability but must not be treated as the current approved source.
