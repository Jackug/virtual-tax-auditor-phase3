Knowledge Governance Principle

The Knowledge Base maintains controlled versions of authoritative information.

Registration → Draft → Human Review → Approval → Controlled Use

Where a reviewer identifies an error or required amendment:

Draft → Edit → New Draft Version → Human Review → Approval

Previous versions are retained and are not silently overwritten.
